# Environmental Storytelling Standards

**Status:** Active (M7 #59)  
**Companion:** `ZONE_VISUAL_STYLE.md` (massing + materials)

## Goal

Every prop cluster should answer: *who was here, what broke, and why it still feels dangerous*.

## Rules

1. **Function first** — place props that support cover, loot, traversal, or readable landmarks.
2. **One story beat per cluster** — e.g. abandoned checkpoint fight, looted shed, failed evacuation — not random junk piles.
3. **Readable at combat range** — silhouette + 1–2 hero props; micro-detail only up close.
4. **Decay hierarchy** — settlement = worn but maintained; checkpoint = contested damage; industrial = neglect + hazard; underground = sealed/failed infrastructure.
5. **Leave negative space** — fog needs empty air; don’t fill every metre.
6. **Player path is archaeology** — spent magazines, barricades facing inward/outward, open doors toward threat.

## Zone beats (Outskirts)

| Zone | Beat | Prop language |
| --- | --- | --- |
| Settlement | Fragile order | Stacked supplies, patched fence, lit-ish yard, stash-adjacent clutter |
| Checkpoint | Contested gate | Boom down, sandbags, overturned barrier, booth ransacked |
| Industrial | Working site gone cold | Dock crates, tanks, pipe leaks, warehouse bay as arena |
| Underground entrance | Threshold fear | Retaining walls, hatch, warning paint, dark mouth |

## Don’t

- Easter-egg clutter that breaks Zone tone
- Symmetrical “level design showcase” prop rings
- Story props that block NavMesh / cover without intent
