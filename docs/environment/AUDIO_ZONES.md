# Ambient Audio Zones (#56)

**Status:** Simplified 2026-10-31 — Outdoor vs Settlement  
**Issue:** #56

## Simple split (current)

| Where you are | Bed (Settings → Audio) |
| --- | --- |
| Outside Settlement walls | **Outdoor** |
| Anywhere inside Settlement compound | **Settlement** |

Optional beds (Industrial / Underground / SettlementIndoor) remain for later; not required for the Settlement gate test.

## Setup

1. Settings → **Audio** → **Seed Greybox Audio Zones** (removes old Yard/Hab volumes, adds one Settlement volume)
2. Save scene
3. Play Mode: leave gate → Outdoor wind; enter compound → Settlement drone  
   Console: `Ambient → Outdoor` / `Ambient → SettlementYard`

## Tuning

Settings → Audio → **Outdoor** and **Settlement** (Clip / Volume / Muffle).
